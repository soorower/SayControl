More than dictation

Say it mid-sentence. It happens right there.

Hold fn and talk. Your words are typed, and these phrases do the job instead of typing themselves.

take a screenshot
A picture of your screen, pasted mid-sentence.
copy the link
The address of the tab in front of you.
attach the PDF from downloads
The newest match, attached for real.
copy the file path
Whatever Finder has selected, as a full path.
open terminal in the downloads folder
A terminal, already standing in that folder.
ask ChatGPT how to center a div
The question opens in ChatGPT, already asked. Claude, Grok and Perplexity too.
scratch that
Takes back the last paste.
send it
Presses Return for you.

Plus command mode, terminal commands and agents that talk back. See every spoken control →
