A · Tray under the window Recommended

Slides out from under the System Settings window, right below the list, and stays glued to it when the window moves. One line says what to do; the arrow, and an icon that glides up into the list, show where.

Cost: low. We only need the window’s frame, which macOS gives without any permission. Nothing sits on the list itself, so it never hides a switch or misses the spot.

B · Drop zone on the list

Draws a dashed “drop here” box over the list, with the icon in a pill under the window and chevrons climbing between them. The most literal of the three.

Cost: risky. Without Accessibility (the very thing we are asking for) SayControl can’t see where Apple put the list, so the box is placed by guess. A different macOS version, text size or window size moves it off the list, and it covers the rows while it is up.

C · Card beside it

A card against the window’s right edge: two numbered steps, the icon with an arrow pointing left, into the list.

Cost: medium. It needs room beside the window; against the screen’s edge it has to flip to the other side, and on a small screen there is room on neither, so it would fall back to A anyway.

Today

A card in the screen’s top-right corner, three sentences, an icon that shakes side to side. It reads as a notification, it is far from the list, and the shake points nowhere.

Whichever you pick

  • It follows the System Settings window when you move it, hides when you switch to another app, and comes back with System Settings.
  • The moment the switch takes, it shows a tick, goes away, and brings SayControl back to the front.
  • The same helper for Accessibility, Input Monitoring and Screen Recording, from the first run and from Settings → Permissions, on every Set Up click.
  • The glide loops every few seconds and stops while you hover or drag the icon. With Reduce Motion on, the path is drawn once and stays still.
  • “Already in the list?” stays one small line until clicked: a switch that reads on but doesn’t work is rare, and only removing it and dragging it back in mends it.
